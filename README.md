# 河北工程大学校园服务

面向河北工程大学的校园学习项目，包含校园集市、跑腿、消息、管理后台与校园导览。

## 本地运行

项目位于桌面 HUE 文件夹，双击 `Start-HUE.cmd`，访问 http://localhost:5173 。
双击 `Stop-HUE.cmd` 停止服务。修改源码后运行 `Build-HUE.cmd`，重新启动。
管理员账号与本机配置见不纳入 Git 的 `本地使用说明.md` 和 `local/`。

前端为 Vue 3 + TypeScript，后端为 Spring Boot。源码目录保留原有工程标识以兼容构建脚本。
使用 VS Code 打开此文件夹，即可编辑代码、查看 Git 差异并通过已有 GitHub 登录同步。

## 校园主题

站点默认学校为河北工程大学。首页使用官网校徽、校门与湖畔高清实景，提供地点搜索、高德导航、学校官网和校园全景入口。
素材出处见 `docs/校园素材来源.md`。本项目为学习实践，非学校官方网站。

## 外部服务

AI、短信及云图片存储尚未配置；本地核心服务可以运行。外部服务配置放在 `local/settings.json`。
