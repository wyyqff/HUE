# 河北工程大学校园服务

面向河北工程大学的校园学习项目，包含校园集市、跑腿、消息、管理后台与校园导览。

## 本地运行

项目位于桌面 HUE 文件夹，双击 `Start-HUE.cmd`，访问 http://localhost:5173 。
双击 `Stop-HUE.cmd` 停止服务。修改源码后运行 `Build-HUE.cmd`，重新启动。
管理员账号与本机配置见不纳入 Git 的 `本地使用说明.md` 和 `local/`。

前端为 Vue 3 + TypeScript，后端为 Spring Boot。源码目录保留原有工程标识以兼容构建脚本。
使用 VS Code 打开此文件夹，即可编辑代码、查看 Git 差异并通过已有 GitHub 登录同步。

## 校园主题

站点默认学校为河北工程大学。首页保留近 8K 湖畔实景，校园全景在站内查看，支持搜索 43 个场景名称。学校全景固定从主广场进入，搜索后需在全景内部选择地点。
素材出处见 `docs/校园素材来源.md`。本项目为学习实践，非学校官方网站。

## 外部服务

短信及云图片存储尚未配置，实际图片上传仍需配置云存储；本地核心服务可以运行。外部服务配置放在 `local/settings.json`。前端已移除 AI 估价及助手入口。

## 交易体验与版本

复用现有 Element Plus 图片、预览、骨架屏和空状态组件，共用商品卡片；支持价格区间、分类、排序与 URL 保存筛选。首页仅展示真实商品，不用演示商品补位。

当前固定浅色主题，统一中文名称，提供真实分类快捷入口、本机发布草稿、封面选择及原图查看器。无效通知偏好、占位客服、自制弹窗与冗余样式已清理。本轮说明和验证范围见 `docs/2026-09-22-交易体验优化.md`；本轮改动前回退标签为 `hebeu-before-experience-polish-20260922`。
